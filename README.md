# ZoomEye-
简单介绍ZoomEye及其常用语法，子域名的收集方法

ZoomEye
一、介绍
ZoomEye（钟馗之眼）是国内知道创宇公司旗下的网络空间搜索引擎，与 Shodan、FOFA 同类，专门用于检索互联网上暴露的设备、网站及其服务组件信息。它通过全球分布的探测节点持续扫描 IPv4、IPv6 及网站资产，帮助安全研究人员从攻击者视角发现资产暴露面。

二、核心定位与数据规模
ZoomEye 的定位是“网络空间测绘”，而非普通网页搜索。它同时覆盖主机设备（IP、端口、协议）和网站组件（操作系统、Web 服务、开发框架等）两个层面。官方数据显示，其探测引擎超过 2000 个，资产数据量达 360 亿条，涵盖 14 万多种组件、2000 多种操作系统和 120 多种设备类型，且对中国用户的数据全部开放。

三、常用搜索语法
语法	作用	示例
app=	按应用/组件搜索	app="Nginx"
service=	按服务协议搜索	service="ssh"
port=	按端口搜索	port="3389"
country= / city=	按国家/城市筛选	country="CN"
os=	按操作系统筛选	os="Windows"
title=	按网页标题搜索	title="后台登录"
vul.cve=	按 CVE 漏洞编号搜索	vul.cve="CVE-2021-44228"
iconhash=	按图标 MD5 搜索	用于识别使用相同 favicon 的资产
以上语法整
理自 ZoomEye 官方帮助与 API 文档。

五、与 ZoomEye 功能类似的搜索引擎
ZoomEye 属于“网络空间测绘”类搜索引擎，它的特点是扫描互联网上的资产（如服务器、摄像头、数据库），而不是普通的网页内容。

下面介绍几种典型的同类引擎：
1.Shodan：最早的物联网设备搜索引擎，适合查找路由器、摄像头、打印机等，语法独特，如 port:3389 country:CN。
2.FOFA：国内白帽汇出品，支持 HTML 源码级检索，语法非常灵活，是国内渗透测试人员常用的工具。
3.Quake（360 quake）：360 旗下的资产测绘平台，数据更新快，对国内资产覆盖比较全面。
4.Censys：学术背景出身，强项在于通过 TLS 证书识别资产，适合寻找特定证书下的服务。
5.Hunter（鹰图）：奇安信出品，国内资产覆盖率很高，语法上使用 web.title 等。

六、子域名收集

（一）什么是子域名？
它是主域名前面加上特定前缀的部分。比如 www.baidu.com 是主域名，而 map.baidu.com（地图）、tieba.baidu.com（贴吧）就是它的子域名。

（二）子域名的作用
企业通常用不同的子域名来区分不同的业务。比如 mail.xxx.com 是邮箱系统，dev.xxx.com 是开发测试环境，admin.xxx.com 是后台管理。

（三）为什么要收集
子域名收集是渗透测试信息收集的重要环节。在渗透测试中，主网站（如官网）通常防护严密，很难攻破。但企业往往会有几十甚至上百个子域名，其中一些可能是测试环境、旧版系统或内部后台。这些“偏门房间”的安保（安全防护）往往比较薄弱，是安全测试中寻找突破口的关键。通过收集和分析子域名，安全研究人员可以更好地了解目标的网络结构及其潜在的攻击面。

（四）如何收集子域名？
子域名收集的方法有很多，通常可以划分为“被动收集”和“主动探测”两大类。在渗透测试的信息收集阶段，最有效的子域名收集方式往往是组合使用多种被动源，再辅以针对性的主动验证。

（五）子域名收集方法：
在主搜索框里尝试下面这两种语法，定位到子域名数据：
domain="guet.edu.cn"：最直接的方式，用来搜索域名相关的资产，包括子域名。
hostname="guet.edu.cn"：专门搜索与该主机名/域名相关的资产，同样能列出子域名。

七、下面再介绍几种主要的子域名收集的方法和工具：

第一类：被动收集

1.证书透明度日志（CT Logs）
是目前最强大、最常用的被动源之一。任何为域名签发的 SSL/TLS 证书都会被记录在公开日志中，而证书里通常包含了子域名信息。
在线查询：直接访问 crt.sh，输入 %.example.com 即可查询。也可以在命令行用 curl 配合 jq 来获取 JSON 格式的结果，方便后续处理。
	工具查询：subfinder 这类工具的核心数据源之一就是 CT logs，它能自动聚合多个来源的结果。

2. 搜索引擎与空间测绘引擎
利用搜索引擎的高级语法或网络空间测绘平台，可以找到被收录或扫描到的子域名。
	搜索引擎：在 Google 或 Bing 中使用site:example.com 语法。DuckDuckGo 对此语法的限制相对宽松，有时能获得更多结果。
	空间测绘引擎：在 Shodan、FOFA、Censys 等平台搜索 hostname:example.com 或类似语法，可以发现暴露在公网上的主机及其对应的域名。

3. 被动 DNS 数据库
这些服务记录了历史 DNS 解析数据，能帮助用户找到那些当前可能已不活跃、但曾经存在过的子域名。
	常用平台：VirusTotal、SecurityTrails、CIRCL Passive DNS 等。其中SecurityTrails 尤其擅长提供历史 DNS 记录。

4. 被动收集工具
命令行工具 Sublist3r：它通过调用多个搜索引擎（Google、Bing、Baidu 等）和 OSINT 源来枚举子域名。
Subfinder：专精于被动收集，速度极快，整合了数十个数据源，是“快速侦察”的首选。
	Amass (OWASP)：功能最全面，除了被动收集，还能进行主动探测、DNS 爆破和网络拓扑构建，适合深度挖掘。
	OneForAll：国内一款功能强大的综合工具，集成了多种收集方式，适合“一键化”作业。

第二类：主动探测

字典爆破
通过使用一个包含常见子域名前缀（如 dev、test、api、mail、vpn）的字典，向 DNS 服务器发送大量查询请求，看哪些能解析成功。这种方法能发现从未公开过的内部服务。
可使用工具：massdns或puredns，它们都是高性能的 DNS 爆破工具。
字典：可以从 SecLists 项目中的 subdomains-top1million-5000.txt 开始，并根据目标行业特点补充词汇。
另外，使用字典爆破时还要注意：爆破会产生大量 DNS 请求，可能被目标察觉或触发限流。同时需要处理“泛解析”（即任意不存在的子域名都指向同一 IP）的问题，通常通过预先随机探测来过滤。
